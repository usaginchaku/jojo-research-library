# ジョジョ関連研究図書館

『ジョジョの奇妙な冒険』各部を読むための、無料全文リンクを中心にした文献図書館です。作品そのものの研究に加え、言語・歴史・文化・地理・服飾・哲学などの背景資料を集めます。

## この図書館の区別

**直接研究**はジョジョ自体を研究対象にする資料、**背景資料**は図書館の編集者が作品との接点を提案する資料です。後者について、荒木飛呂彦が参照した文献であるとは主張しません。影響関係を確認できる作者発言等があれば、別途その出典を記録します。

学術誌掲載論文・紀要・学位論文・解説・一次史料などの種類を記録します。査読の有無は、確認できた範囲だけを表示します。無料全文へのアクセス確認は、論文の結論の正しさや、全頁の精読を保証するものではありません。

2026年10月22日の調査を起点にしています。各部5件を初期目標とし、現在の件数は[目録](CATALOG.md)で確認できます。同じ資料が複数の棚に載る場合があるため、棚ごとの件数の合計と資料の総数は一致しない場合があります。

## 追加・更新する

現在の目録の正本は **[data/catalog.json](data/catalog.json)** です。ここを更新して、Python 3で次を実行します。

```sh
python scripts/build_catalog.py
python scripts/build_catalog.py --check
```

Markdownの目録・部別の棚・CSV・RISは同じデータから生成します。個別の読書メモは `notes/資料ID.md` に置き、[雛形](NOTE-TEMPLATE.md)を使えます。

日常の収集をZoteroに移した後は、Zoteroで管理する書誌情報をこの目録へ反映する流れに切り替えます。現在のスクリプトにはZoteroとの自動同期はありません。両方を別々に編集する運用は避け、反映する元を決めてください。

[採録・更新のルール](CONTRIBUTING.md)と[作業状況](STATUS.md)も参照してください。

## 長く読めるように

PDF直リンクに加えて、書誌ページ・DOI・確認日を保存します。保存が認められるPDFは手元のZotero等にも保存してください。外部サイトの永久公開は保証できません。

公開するのは文献情報、原文へのリンク、自作の短い説明と読書メモです。無料公開と転載・再配布可能は別なので、原文PDFや図版の公開には資料ごとの利用条件を確認します。

## 使う道具

- [Zotero](https://www.zotero.org/support/sync)：書誌情報等の同期は無料・無制限。添付ファイルのZotero Storage同期は無料300 MBで、ローカル保存容量とは別です。
- [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)：GitHub Freeでは公開リポジトリから公開できます。
- [Quartz](https://quartz.jzhao.xyz/)：Markdownのメモを、検索・相互リンクのある読書サイトへ発展させる選択肢です。このリポジトリは現在Markdownの図書館です。
