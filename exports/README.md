# Zoteroへ取り込む

このフォルダのファイルは **インポート用** です。Zoteroアカウントへの直接登録・同期はまだ行っていません。

- [jojo-library.ris](jojo-library.ris)：目録の全資料。
- [zotero-initial-6.ris](zotero-initial-6.ris)：最初に集めた6件だけ。

## 取り込み方

1. Zoteroのデスクトップアプリで「ファイル」→「インポート」を開く。
2. ファイルからのインポートを選び、どちらか一方のRISファイルを指定する。
3. 新しいコレクションとして取り込み、「ジョジョ研究図書館」などの名前を付ける。
4. 題名・著者・年、部・分野・直接研究/背景資料のタグを確認する。
5. 全文URLは各項目のノートに残してある。保存できるPDFは原文ページから取得し、該当項目へ添付する。

全件版は初期6件も含みます。両方を取り込むと重複するため、通常は全件版だけを使います。既に登録済みの資料がある場合は、Zoteroの重複アイテム確認を使って整理してください。

## 保存される内容

書誌情報、元の書誌URL、DOI、部と分野のタグ、図書館ID、全文URL、確認日と確認範囲、作品との関連説明を含みます。著者名は元の目録表記を保存しています。取り込み後、姓・名の分かれ方や日本語氏名の表示を確認してください。

「読書メモあり」のタグは、このリポジトリにメモがあるという意味です。それ以外には読書状況の初期タグとして「未読」を付けています。無料アクセス確認済みという状態と、精読済みという状態は別です。

RISの雑誌名・刊行元の欄には、目録の掲載情報をそのまま入れています。巻・号・ページを完全に分離した書誌情報が必要な場合は、DOIや刊行元のページで補完してください。資料種別や査読状況の細かな区別はノートにも保存しています。

この書き出しにはPDF本体を含めていません。HTML全文とPDFを誤って区別しないため、添付ファイルの自動取得は指定していません。

## 更新する

現段階の正本は `data/catalog.json` です。リポジトリのルートで次を実行すると、目録・部別の棚・CSV・RISをまとめて更新できます。

```bash
python scripts/build_catalog.py
python scripts/build_catalog.py --check
```

Zoteroで書誌を管理する運用へ移ったら、ZoteroとこのJSONを両方手作業の正本にせず、書き出しから更新する運用に切り替えてください。現在のスクリプトはZoteroからの同期処理を含みません。
